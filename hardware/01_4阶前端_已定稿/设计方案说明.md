# 方案二 · 第一部分：4 阶前端滤波器（已定稿 · 490 kHz 设计点）

> 本版本将 Stage 2 的 GBW 要求从 151.65 MHz 降到 **148.62 MHz**，
> 使手上的 **THS4551（GBW = 150 MHz）可用**。

## 设计规格

```
Name: Lowpass, Multiple Feedback Fully Differential, Chebyshev
Part: Ideal Opamp
Order: 4
Number Of Stages: 2
Gain: 1 V/V (0 dB)
Allowable PassBand Ripple: 0.5 dB
Passband Frequency: 490 kHz      <- 由 500 kHz 改到这里
Corner Frequency Attenuation: -3 dB
Stopband Attenuation: -32 dB
Stopband Frequency: 1 MHz
Circuit Topology: MultipleFeedback_Fully_Differential
```

## 风险与退路

**唯一风险**：Stage 2 的 GBW 余量只有 **0.9%**（148.62 vs 150 MHz）。

FilterPro 的 "Min GBW req." 是**保守估算**（保证极点位置准确）。
实际 THS4551 在 150 MHz 下会让 Stage 2 的 Q 略降，造成的响应偏差在零点几 dB 量级，
对 ±5 mV 的幅值精度要求影响可忽略。

**退路**：若实测发现偏差超预期，可把 4 阶降到 **480 kHz**
（Stage2 GBW → 145.58 MHz，余量 3%，通带峰值 +0.745 dB，仍安全）。
备选数据见 `04_备选_4阶前端其它设计点\`。

## 其它注意事项

1. **通带峰值 +0.714 dB 出现在 447 kHz**，是 Chebyshev 的正常肩部响应。
   500 kHz 处为 **−0.545 dB**，需在树莓派侧用实测扫频曲线做幅频标定。

2. **C1 与 C1diff 建议用 1% 或成对匹配件**：差分两半若不一致会劣化共模抑制。
   C2 用 5% 可接受（它不在差分对称位置）。

3. **1 MHz 干扰残留 2.41 mVpp**，已低于 ±5 mV 预算，
   建议在谱线识别时把 1 MHz 附近的谱线作为已知干扰剔除，不计入分量统计。

4. **Stage 2 单独用 THS4551**，Stage 1 与现有板的 2 阶 FDA 可继续用 THS4521
   （需求分别 20.62 MHz 与约 55 MHz，均有充裕余量）。
