## 1. 按问答逐条核对

### 1.1 信号定义（Q1、Q2、Q3、Q7、Q8、Q10、Q13、Q37）

| 条目 | 要求 | 现状 | 判定 |
|---|---|---|---|
| Q1 | U_pp 指**整体合成波形**的总峰峰值 | 测试按合成分量解析求 max−min，不是分量相加 | ✅ |
| Q2 | 频谱「幅值」= **峰值** | 频谱每根谱线标注的是正弦峰值 mV | ✅ |
| Q3 | 各频率分量幅值**均不小于 5 mV** | 见 1.2（发现一个真风险，已修） | ⚠️→✅ |
| Q7 | 只有「基波 + 1~2 个谐波」，不是方波/三角波 | 验收用例全部按此构造（方波仅作算法鲁棒性自测） | ✅ |
| Q8/Q37 | 最多 2 个谐波；谐波最高 ≤500 kHz | 采集带宽 1.77 MHz，拟合带上限 520 kHz | ✅ |
| Q10 | 三种输入都是**纯交流，无直流** | U_dc 通道保留但实测 ≈0；频谱不显示直流分量 | ✅ |
| Q13 | 全部成分限于 10k~200k / 10k~500k | 幅频表覆盖 10k~550k，200k 档谱宽可切 | ✅ |

**Q3 的风险（重要）**：问答只说「各分量 ≥5 mV」，**没有保证基波最大**。原代码的基频判据把「幅度 < 最大峰 5% 的谱峰」排除在候选之外——若基波 5 mV、3 次谐波 120 mV（总 U_pp 约 250 mVpp，完全合法），5 mV < 6.25 mV 会被排除，f₁ 会直接报成 3 次谐波（误差 100 kHz，远超 1 kHz 限）。

**已修**（`lsa_dsp.py` `find_fundamental`）：候选门限由「最大峰的 5%」改为**绝对幅度** `max(4 mV, 2% 最大峰)`。离线验证：

```
基波5mV + 3次120mV        f1= 50000.0 Hz  OK
基波5mV + 3次120mV(反相)  f1= 50000.0 Hz  OK
基波5mV + 2次120mV        f1= 50000.0 Hz  OK
正常三音                  f1= 50000.0 Hz  OK
单音5mV                   f1= 50000.0 Hz  OK
100kHz 方波(49次)         f1=100000.0 Hz  OK   ← 没有牺牲方波鲁棒性
```

## 2. 需要动的地方

### 2.1 硬件（3 条，必须改）

1. **单路 5 V 供电**
   现有电源树（网表核实）：`XT60 → +12V → TPS563200 → +5V(DGND) → TPS7A4701 → +5V(AGND) → LM2776 → −5V`。
   12 V 只用于继电器线圈和一级降压。改法二选一：
   - 外部 5 V 直接替换 XT60 输入，另加 5 V→12 V 升压模块供继电器（继电器实测不动作，也可直接把继电器回路断开）；
   - 或把继电器驱动改成 5 V 型，彻底取消 12 V。
   **注意**：赛题期间继电器功能实测无效，最省事的做法是断开继电器供电，仅保留 5 V 主路。

2. **BNC 母座**
   板上 SMA 座换成 `BNC 母座（直插/弯插 50 Ω）`，或在原有焊盘飞线到板载 BNC 座。若来不及改板，必须自备 **SMA 转 BNC 电缆**，且电缆信号源端必须是 BNC 公头——测试时随装置一起带。

3. **显示屏 ≥6 英寸**
   板上 3.5 寸 SPI 屏不合格。现用的外接 7 寸 HDMI 触摸屏（1024×600）满足要求，但必须固定到装置面板上、由同一路 5 V 供电（7 寸屏通常需 5 V/2 A，注意与树莓派合计电流）。

### 2.2 软件（已改完，需部署验证）

- `lsa_dsp.py`：基频候选门限改为绝对 4 mV（本次修改，待部署到树莓派后重跑全题目测试确认）。
- 其余条目无需改动。
