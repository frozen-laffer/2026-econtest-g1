## 2. ADC 差分连接（**最重要：无需改板**）

STM32G474 的差分通道是**固定通道对**。本板三个通道恰好接在成对的差分引脚上：

| 通道 | FDA | VOUT+ → | VOUT- → | ADC 差分对 | 串联 | 差分电容 | 反馈电阻 |
|---|---|---|---|---|---|---|---|
| CH1 | U20 (THS4521) | **PA1** = ADC1_IN2 | **PA0** = ADC1_IN1 | ADC1 IN1/IN2 | R115 / R118 = **33 Ω** | **C94 = 100 pF** | R113 / R120 = 2.49 kΩ |
| CH2 | U23 | **PA7** = ADC2_IN4 | **PA6** = ADC2_IN3 | ADC2 IN3/IN4 | R127 / R130 = 33 Ω | C110 = 100 pF | R124 / R131 = 2.49 kΩ |
| CH3 | U26 | **PA9** = ADC5_IN2 | **PA8** = ADC5_IN1 | ADC5 IN1/IN2 | R139 / R142 = 33 Ω | C126 = 100 pF | R136 / R143 = 2.49 kΩ |

**结论**：FDA 全差分输出已硬连线到 ADC 的差分对。固件只需
`DIFSEL` 置位 + `SingleDiff = ADC_DIFFERENTIAL_ENDED`，**纯软件改动**。

> 注意：直流偏置走 SIG_VCM（= VREF/2），FDA 与 INA 都是单电源下的中点偏置。因此
> **ADC 读到的是"围绕中点的交流 + 偏置"，必须做直流校正后才能得到真实电压。**

## 3. 输入级（每通道结构相同，共 3 组）

```
RF1 (SMA, 50Ω)  ──┐
                  ├─→ [K1 继电器] ─→ 33Ω/100pF ─→ INA128(U19) ─→ THS4521(U20) ─→ ADC1
TIA1_OUT (U30)  ──┘        ↑ 源选择
                           └─ 另有一组触点接隔直电容 C79，实现 AC/DC 耦合切换
```

### 3.1 继电器（6 × G6K-2F-Y，12 V 双线圈 DPDT）

| 继电器 | 功能 | 触点所在网络 |
|---|---|---|
| K1 | CH1 输入源选择（SMA `IN1+` ↔ `TIA1_OUT_P`） | K1-3→IN1+，K1-4/5→C79(隔直) |
| K2 | CH1 第二组触点（AC/DC 耦合 + TIA 通路） | K2-3→K1-6，K2-6→TIA1_OUT_P |
| K3 / K4 | CH2 同上 | IN2+ / TIA2_OUT_P |
| K5 / K6 | CH3 同上 | IN3+ / TIA3_OUT_P |

**线圈驱动（6 组，每组相同）**：

```
+12V ── 继电器线圈 ── 漏极(AO3400A) ── 源极 ── DGND
                        ↑ 栅极 ← STM32 GPIO（经 1 kΩ）
        续流二极管 M7 (D2..D7)：阳极 → +12V，阴极 → 漏极
```

⚠️ **控制极性**：STM32 输出**高电平 → MOSFET 导通 → 继电器吸合**。
现有 `afe.c:70-79` 的注释与之不符，**必须按实测重写语义**。
上电默认（GPIO 复位为低）→ 全部释放。

## 4. 增益链（**G=2 已核实存在**）

### 4.1 增益切换 = BL1551B 选 INA128 的 R_G

```
U19(INA128) RG(引脚1/8) ─── BL1551B(U18) 公共端 B(引脚4)
                              ├─ A1(引脚1) ─→ R109 = 2.61 kΩ  (0402WGF2611TCE)
                              └─ A2(引脚3) ─→ R110 = 49.9 kΩ  (RP0402BRD0749K9L)
                             ENB(引脚6) ←→ PGA1_EN = STM32 PC3
```

料号 → 阻值译码：`0402WGF2611TCE` → `2611` = 2.61 kΩ；`RP0402BRD0749K9L` → `49K9` = 49.9 kΩ。

INA128 增益：`G = 1 + 50 kΩ / R_G`

| R_G | 计算增益 | 说明 |
|---|---|---|
| 49.9 kΩ | **×2.002** | ← **你说的 G=2 就是这一档** |
| 2.61 kΩ | **×20.16** | 高增益档 |
| 1.301 kΩ（两路同选） | ×39.43 | 未定义/不建议 |

**增益链（CH1）**：

```
V_in ──[INA128 G=2 或 20.16]──→ V_ina
     ──[THS4521 FDA: Rf=2.49k(R113) / Rg=1.27k(R114)]──→ 差分 V_fda
     ──[33Ω + 100pF]──→ ADC1 差分输入
```

FDA 增益（差分输出 / 单端输入）：`A_fda = Rf / Rg = 2.49 k / 1.27 k ≈` **1.96**

阻值均由网表 PARTTYPE 直接译出（Yageo 料号规则：`RT0402BRD071K27L` → `1K27` = 1.27 kΩ；
`0402WGF2491TCE` → `2491` = 2.49 kΩ）：

| 元件 | 位号 | 料号 | 阻值 |
|---|---|---|---|
| FDA 反馈 Rf | R113, R120 | `0402WGF2491TCE` | 2.49 kΩ |
| FDA 输入 Rg | R114, R117 | `RT0402BRD071K27L` | **1.27 kΩ**（0.1% 精密） |
| ADC 串阻 | R115, R118 | `RT0402BRE0733RL` | 33 Ω（0.1% 精密） |
| INA 输入串阻 | R111, R116 | `RT0402BRD071K27L` | 1.27 kΩ |

### 4.2 量程估算（**需实测校正**）

| INA 增益 | V_in 单端摆幅 | 差分摆幅(V_fda) | 是否适配 ±3 V 差分满量程 |
|---|---|---|---|
| ×2 | ±0.78 V | ±1.53 V | ✅ 偏小，浪费 ~1/2 量程 |
| ×20.16 | ±77 mV | ±1.52 V | ✅ 合适 |

> **注意**：以 MAX6071 = 3.0 V 为 VREF 时，ADC 差分满量程为 **±VREF = ±3.0 V**（每脚 ±1.5 V）。
> 上表按 `A_fda ≈ 1.96` 估算，**精确系数必须用直流源逐档标定后写入上位机配置**。

### 4.3 与现有固件的不一致

| 项目 | 硬件实际 | 现有 `afe.c` | 处理 |
|---|---|---|---|
| 增益档位 | ×2.002 / ×20.16 | `AFE_GAIN_1X` / `AFE_GAIN_20X` | 重写语义与系数 |
| `AFE_GetTotalGain()` | 应为 2.002 / 20.16 | 返回 1 / 20 / 0.05 / 1 | **必须重写** |
| ADC 参考 | MAX6071 = **3.0 V** | 硬编码 `VREF 3.0f` ✅ | 保留，但要叠加增益系数 |
| ADC 满量程码 | 12-bit 差分 → ±2047 | `ADC_MAX 32767` ❌ | **必须改** |

## 5. 跨阻放大器（TIA，可选功能）

`U30 (AD8608 四运放)` 提供 4 路 TIA：

| TIA | 运放 | 反馈 | 输入电阻 | 输出 → |
|---|---|---|---|---|
| TIA1 | U30-A (OUTA) | R146 = 1 MΩ ∥ C130 = 4.7 nF | R145 = 680 Ω → 测试点 U27 | `TIA1_OUT`，经 H3 或 K1 → INA |
| TIA2 | U30-B | R150 = 1 MΩ ∥ C134 = 4.7 nF | R148 = 680 Ω → U29 | `TIA2_OUT` |
| TIA3 | U30-C | R151 = 1 MΩ ∥ C135 = 4.7 nF | R149 = 680 Ω → U31 | `TIA3_OUT` |
| TIA4 | U30-D | R147 = 1 MΩ ∥ C131 = 4.7 nF | R152 = 680 Ω → U32 | `TIA4_OUT`（仅测试点 U28） |

- 跨阻 `R_f = 1 MΩ`，带宽受 `C_f = 4.7 nF` 限制（约 **34 Hz**）→ **这是准静态电流测量，不是高速 TIA**。
- `H1/H2/H3` 三个 2.54 mm 跳线：短接则 `TIAx_OUT` 直连 `INx+`（旁路继电器）。
- 逆输入经 680 Ω 到测试针 → 可测光电流/电流输入。

## 6. 电源与地

```
USB-C → CH224A (PD诱骗) ┐
XT60 (CN1) ─────────────┴→ +12V ─┬→ 继电器线圈 ×6
                                  ├→ TPS563200 → 降压
                                  ├→ TPS62913 → 降压
                                  └→ ...
TPS7A4701 → +5V(DGND) / +5V(AGND)
TPS7A9401 → 低噪 LDO
LM2776  → -5V(AGND)   （给 INA128 负轨）
AP2112K-3.3 → +3V3    （RP2040 域）
U3 MAX6071 → VREF+ = 3.0 V（经磁珠 L3）
```

**模拟/数字电源分离**：`+3V3(DGND)`（数字）与 `+3V3(AGND)`（模拟）是**两个独立网络**，
每路模拟供电经磁珠（L18/L21/L24 等）从模拟域引入。

**地分割（重要，勿破坏）**：
- `AGND` 与 `DGND` 是**两个独立网络**
- 由 **R73 + R74（两个 0 Ω 并联）** 单点桥接
- `PE`（屏蔽/外壳）经 **L11 磁珠** 接 DGND
- **PCB 布局时必须保证 AGND/DGND 仅在此单点相连**

## 7. RP2040 的真实角色：调试探针（**修正此前的误判**）

```
RP2040(U8) GPIO2 ─27Ω(R45)→ SWCLK  ─→ STM32 PA14
RP2040     GPIO3 ─27Ω(R46)→ SWDIO  ─→ STM32 PA13
RP2040     GPIO1 ─ 0Ω(R44)→ NRST   ─→ STM32 PG10
RP2040     GPIO4 ─27Ω(R47)→ DAP_TX ─→ STM32 PC5
RP2040     GPIO5 ─27Ω(R48)→ DAP_RX ─→ STM32 PC4
RP2040     GPIO25─470Ω(R49)→ LED3
RP2040     USB_DP/DM ─27Ω→ D1(USBLC6-2SC6) → 独立 Type-C (USB1)
RP2040     QSPI ×6 → U10 (自己的 W25Q16)
```

- **RP2040 = 板载 CMSIS-DAP / Picoprobe 类调试器**，用于烧录与调试 STM32。
- **RP2040 不接显示屏、不做信号处理、不参与数据通路。**
- ⚠️ 此前判断"RP2040 是死件"系解析脚本字段错位所致，**已更正**。
- 决策待定：保留（省一个调试器）／删除（省 BOM 与面积，但需外部探针）。

`U17`（3.5" 480×350，含触摸）**全部接 STM32**，RP2040 一根未接：

| TFT 引脚 | 网络 | STM32 引脚 |
|---|---|---|
| SCK | `SCK` | PB13 (SPI2_SCK) |
| SDI(MOSI) | `SDI(MOSI)` | PB15 (SPI2_MOSI) |

| CS | `CS` | PB12 (SPI2_CS) |
| DC/RS | `DC/RS` | PB10 |

> ⚠️ **注意**：网表显示屏挂在 **PB13/PB14/PB15**（= SPI2 引脚），
> 而现有固件 `ILI9488.c:26` 用的是 **SPI1**（PB3/PB4/PB5）。
> **这是一个必须核实的冲突** —— 要么固件选错了 SPI，要么网表与实物不一致。
> **在跑显示相关测试前必须先确认这一点。**

## 10. 未核实 / 待实测清单

以下项目**本文件无法从网表确定**，必须实测：

1. **FDA 的 Rg 实际阻值**（`0402WGF1271TCE` 解码为 1.27 kΩ，需万用表确认）→ 决定 `A_fda` 精确值
2. **INA128 两档实际增益**（受电阻公差影响）→ 逐档直流标定
3. **继电器触点拓扑**（K1-2/K1-7、K1-4/K1-5 的内部对应）→ 需导通测试确认 AC/DC 切换逻辑
4. **屏的 SPI 总线到底是 SPI1 还是 SPI2**（见 §8 冲突）
5. **SIG_VCM 实际电压**（应为 VREF/2 ≈ 1.5 V）
6. **单端 vs 差分接法**：`IN1-` 网络只接了 R83(1 MΩ) 与 R111(1.27 kΩ) 到 AGND，
   说明 INA128 是**单端输入**（牺牲 CMRR）。若要真差分需改板。
7. **各电源轨实测电压与纹波**
8. **`+12V` 继电器的实际吸合/释放时序与尖峰幅度**
