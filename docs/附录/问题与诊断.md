## A. 直接影响赛题验收的问题

### A1　谐波相位导致 Upp 超预算（**已验证，最高优先**）

| f₁ | 谐波 | 0° | 90° | 180° | 270° |
|---|---|---|---|---|---|
| 50 kHz | 3+4 次 | −0.36 | +0.53 | +0.02 | +0.11 |
| 100 kHz | 3+4 次 | +0.15 | **+7.20** | −0.32 | **+6.03** |
| 150 kHz | 2+3 次 | −0.68 | **+5.08** | −0.20 | **+7.50** |
| 200 kHz | 2 次 | −0.56 | **+7.89** | −0.44 | **+7.09** |
| 250 kHz | 2 次 | +0.55 | **+7.06** | +0.44 | +5.99 |

（表中为 Upp 误差，mV；预算 ≤5 mV。激励为「基波 + 1~2 个等幅谐波，各分量峰值 90 mV」。）

- **现象**：0°/180° 全部 ≤0.7 mV；90°/270° 在 100~250 kHz 一律 5~8 mV，**超预算**。
- **根因**：模拟链对不同次谐波的相移不是基波相移的 k 倍（`Δφ_k = ∠H(kf₁) − k∠H(f₁)`）。装置用实测相位做最小二乘重建，重建出的波形与输入波形**形状不同**，于是 max−min 偏大。
- **诊断要点（ASTRA 指出、已采纳）**：最初测到的 `(k−1)×90°` 规律**主要是相位约定造成的假象**——`harm_deg` 用 `atan2(b,a)` 给的是 −φ，而 AFG 的“零初相正弦”在余弦约定下恒带 −90°。按正确约定换算后，链路自身相移只有 **+1°~+15°**。
- **已证明可补偿**：在 200 kHz / 二次谐波 / 谐波相位 90° 上做闭环扫描（直接找使误差最小的补偿角，不依赖任何约定）：

  | 补偿角 | 0° | +6° | +8° | +10° | **+11.4°** | +14° | +20° |
  |---|---|---|---|---|---|---|---|
  | 误差 mV | +9.07 | +5.46 | +3.46 | +2.55 | **+0.92** | +3.55 | +7.21 |

  最优角 **+11.4°**，误差 +9.07 → **+0.92 mV**，进预算。
- **处置**：把「闭环扫角」做成 21 点表那样的正式标定（每个目标频点扫 9 个角，取极小点写回 `eq.json` 的 `phase` 字段）。预计 6 分钟一轮。
- **状态**：补偿代码已在 `lsa_dsp.py` 中（`PHI_ENABLE`，默认关闭，`LSA_PHI=1` 打开，`LSA_PHI_OVERRIDE=角度` 可强制单角）；表只有 4 行 f₁ 实测，需补齐。

### A2　300~400 kHz 的幅频表误差导致 −8.3 mV（**已验证，非相位问题**）

- **现象**：f₁=100 kHz、基波+3次+4次、相位全 0° 时，无论补偿开关，误差都是 **−8.3 mV**。
- **证据**（同一次采集的分量幅值，设定各为 90 mV）：

  ```
  a₁=89.69   a₂=3.71(应为 0)   a₃=88.16(应 90)   a₄=89.06(应 90)
  ```

  三次谐波少 1.84 mV（−2.1%）、四次少 0.94 mV（−1.0%）。
- **根因**：300/400 kHz 处链路衰减大，EQ 要放大 ×3~4，**21 点表在该区间 1~2% 的误差被放大**成 5~8 mV 的 Upp 误差。表的采样点在 300/325/350/375/400/440 kHz，仍有插值误差。
- **处置**：300~450 kHz 之间加密并多次平均重标（把表误差压到 ≤0.3%）。
- **附带发现**：出现一个**真实的二次谐波 3.71 mV**（源里没有）。可能是 ARB 在 100 kHz 处的自身失真，也可能是链路非线性，**待验证**。

### A3　50 mVpp 档系统性偏高 +2.9 mV（已验证，已有软件对策，待复测）

- **现象**：项2 的 40 点矩阵里，50 mVpp 一行在 200~500 kHz 系统性 **+2.85~3.13 mV**，而 100~250 mVpp 全部 ≤0.66 mV。
- **根因**：信号源有固定的 **508.4 kHz 杂散**（≈1.3 mV 峰值 / 2.6 mVpp）。AFG 输出开、幅度设 0 时仍有 **1.13 mV**；输出关则 **0.000 mV** → 来源在信号源侧，不是板子自激。该杂散把分位数法的 Upp 抬高。
- **对策（已实现，待真机复测）**：`measure()` 改用「谐波重构 + 三判据」（绝对误差预算 ≤5 mV、残差稀疏度 ≥0.60、频率归属），离线验证 1.3 mV 孤立杂散被正确排除。**因为硬件离线，这套改动还没在真机上跑过。**

### A4　基波幅度重复性 1.3%（待验证）

- **证据**：同一激励、两次采集 `a₁=89.55` 与 `a₁=90.68`（设定 90 mV）。折算到 Upp 约 2 mV。
- **可能来源**：EQ 插值、信号源稳定度、或采集起点不同导致的拟合差异。**尚未定位**。

## B. 硬件侧限制与未结案项

### B1　模拟链是 8 极点、1.2 MHz 处 −74 dB（**是优点，不是缺陷**）

题3 的 u_j 是**要抑制的干扰**（说明 3：四项都只测 u_b）。实测滚降：

```
 550k −20.9dB | 600k −25.7 | 650k −30.9 | 700k −35.9 | 760k −41.6
 820k −46.9   | 900k −53.4 | 1.06M −64.9 | 1.15M −70.7 | 1.25M −76.7 | 1.6M −91.3
```

斜率 −38.6 / −47.0 / −47.7 / −48.4 dB/oct → **8 个极点**（主板二阶 + 外接四阶 + INA128 带宽 + 输出级）。
**代价**：600 kHz 以上完全不可测（该频段超出赛题范围，无影响）。
**注意**：报告里应写成「局部斜率观察 + 经验拟合」，不能写成已证实的电路机制。

### B2　AFE 三条继电器路径全部不动作（已验证，未修）

- AC 耦合切开后 `Udc` 不变；20× 衰减切开后通路断（codes 全 −1）；×20 增益切开后只有软件系数变、原始码不变。`GPIOx_ODR` 全 0 → 实际停在 DC / 1× / ×2 档。
- 影响：**不影响赛题**（赛题只需要固定档位），但面板上的三个开关实际是装饰。

### B3　ADC5 存在 +738 mV 直流偏置（未结案）

- 三路里只有 ADC5 偏置异常（另外两路正常）。已排除：不是 ADC3 寄存器地址笔误、不是单端/差分配置残留。
- 影响：挤占动态范围（余量从 ±764 mV 降到 ±26 mV 附近，需实测确认）。**待查**：差分校准、DIFSEL、序列、OFR、硬件分压。

### B4　模拟板 32 MHz 自激（固有，已排除危害）

- fs=3.542 MSPS 下 32 MHz 折叠到 `|32−9×3.542|=122 kHz`，本来会落在分析带内。
- 实测 20~200 kHz 内最强分量 **0.069 / 0.070 / 0.058 / 0.050 mV**（四档，≈−71 dB，占 5 mV 预算 1.4%），**125 kHz 处一根线都没有** → 无威胁。混叠预算应按 **−67 dB** 论证，不要用局部斜率外推到 −143 dB。

### B5　板子被 DAP 停住时整机“死机”（运维问题）

- SWD 调试器把 MCU 停在断点上时固件不跑、W5500 不响应，表现为 ping 不通、`eth0` 掉载波。
- 处置：`openocd -f interface/cmsis-dap.cfg -f target/stm32g4x.cfg -c "adapter speed 2000" -c "init" -c "reset run" -c "shutdown"` 复位即可。

## C. 固件与协议

### C1　三路交替采样失效（已验证，已放弃）

- 交替后镜像分量比基波还强（`fs/3 ± f`），两路相位错位恒定 **13 / 23 个样本**（理想应为 1 / 2）。
- **13 = 3×4+1、23 = 3×7+2** → 更像“三路 DMA 缓冲区起点晚了整周期”（TIM8 已跑起来才 `HAL_ADC_Start_DMA`），不是触发路径差几拍。
- ASTRA 建议的修法：严格按「停 TIM8 → 设 ARR/CCR + EGR.UG → 初始化三路 DMA → 最后统一 CEN=1」的顺序；先用 P=12/24 验证“每个触发都被接收”。
- **收益判断**：本题只需 10k~500k，单路 Nyquist 1.77 MHz 已覆盖；固定样本数下提高 3 倍采样率反而把观测时长缩短 3 倍。**建议放弃，不再投入。**

### C2　双 ADC 硬件交织不可用（已验证，已放弃）

`ADC_DUALMODE_INTERL` 的 `DELAY` 只有 1~12 个 ADC 时钟；需要 7.5 周期，取 7/8 有 3.3% 相位误差（500 kHz 处镜像 −30.6 dB = 3.7 mV）。实测 `DELAY` 完全没生效（读数精确 2.000 倍）。

### C3　单路采样率上限 3.542 MSPS

受 ADC 时钟 56.67 MHz 与 2.5 周期采样时间（15 周期 = 264.7 ns）限制。档位 3.542 / 2.656 / 2.125 / 1.771 MSPS → 频率分辨率 432 / 324 / 259 / 216 Hz（@16384 点），均已满足 ≤500 Hz。

### C4　板子只允许一条 TCP 连接

界面保活与采集争用会把应答插进数据流，表现为 `头部 magic 错误`。上位机已用 `RLock` + `drain()` + 保活避开采集规避；固件侧有 120 s 空闲看门狗。

## D. 上位机

### D1　相位表未定标（见 A1）　——唯一真正阻塞四项验收的软件项

### D2　200 kHz 以上波形判型不可信

`wave_kind` 返回 `'sine?'`：`3·f₁ > band_hi` 时判型必然不可信，按设计退回分位数法。**这是设计行为**，不是 bug。但界面上显示 `sine?` 会让人以为出问题，可改成不显示。

### D3　THD 在带外杂散存在时会失真

THD 按“所有整数次谐波能量 / 基波”算，信号源 508.4 kHz 杂散不是谐波，不计入；但若杂散恰好落在某次谐波上会被误算。目前无实测反例。

## 附录：已解决项（供对照）

| 问题 | 结论 |
|---|---|
| 差分 ADC 结果读错 | G4 差分在 DR[11:0] 是**偏移二进制**（2048=0），不是补码 |
| 频率读成 2 倍 | `ADC_ReconfigSingleEnded` 把采样时间改成 12.5 周期 → 已统一 2.5 周期 |
| ADC2 永不触发 | EXTSEL=3 在 ADC12 组实为 TIM2_CC2 → 改 TRGO2（EXTSEL=8） |
| 周期窗首尾接缝大 | `slice_periods` 只能取整数样本 → 改线性重采样（后升级 Catmull-Rom 三次） |
| 4 次谐波被当纯正弦 | `waveform_kind` 只查 2/3/5/7 次 → 改为检查带内全部谐波 |
| 题2 高频成分漏算 | `harmonic_fit` 的 K 上限 40 只覆盖 400 kHz → 改 `band_hi=520 kHz`、`max_k=64` |
| 500 kHz 读数“漂移” | 是**预热爬升**（+6%，约 15 分钟）后稳定；平台期 12 分钟极差 0.08% |
| 扫频校准不可用 | AFG 的 SCPI 扫频不生效 → 换成 21 点引导式阶梯校准 |
| 校准表被改坏 | 每点重写 `FUNC`/`VOLT:UNIT` 会让后续 `FREQ` 被丢弃 → 每点只写 `FREQ`+`AMP` |
| 标定存了满量程假值 | 输入端接着信号时点了“校准” → 该按钮已删除 |
