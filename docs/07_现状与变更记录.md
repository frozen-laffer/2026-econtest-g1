## 3. 信号源：从 AFG-2225 到 DG4202 双支持

### 3.1 为什么要用谐波模式

AFG-2225 的任意波只有 4096 点、±511 码、重放上限 120 MSa/s，做 250 mVpp、基波 29.3 kHz 的多阶谐波时，量化噪声与重建杂散会直接影响 ±5 mV 判据。DG4202 自带**谐波模式**（内部分量合成），没有量化损失，因此优先使用。

### 3.2 谐波模式的四个要害（实测）

1. **总开关是 `HARMonic:USER` 16 位掩码**：`X` + 15 位（对应 2~16 次），出厂默认全 0。不写掩码，`HARM:AMPL` 写得进、读得回、错误队列还干净，但输出上一根谐波都没有。
2. **`HARM:AMPL` 是绝对 Vpp**，未写过的阶次默认 **1.2647 Vpp**，所以必须把不用的阶显式清零。
3. **阶次上限 16**（超了会被静默钳位或报 `-220`）。
4. **相位只被执行一部分**（写 180° 只到理论的一半），所以需要精确相位时不用谐波模式。

### 3.3 什么时候改用任意波（ARB）

- 相对阶次 > 16（赛题 题2-D 的 17 次）；
- 分量不是基波的整数倍（题3-A/3-B 的干扰 41×F0、35×F0）；
- 需要精确非零相位。

ARB 的唯一大坑：`DATA:DAC` 收的是**偏移二进制 0~16383、8192 为零电平**，发有符号码会让负半周回卷，输出变成全波整流（峰峰值只有一半、二次谐波 42%）。

### 3.4 判定规则（`lsa_src.Dg4202.load_wave`）

| 条件 | 走向 |
|---|---|
| 带干扰 / 无阶次信息 / 只有基波 | ARB（并在界面提示原因） |
| 阶次非整数、相对基波非整数倍 | ARB |
| 要求非零相位 | ARB |
| 相对阶次 > 16 | ARB（提示"超过 DG4202 谐波上限 16 次"） |
| 其余 | **谐波模式** |

细节与命令顺序见 [`06_DG4202接入说明.md`](06_DG4202接入说明.md)。

## 4. 测量链路的三个开关（只对 DG 生效）

DG4202 输出在 **≈585–600 kHz 有一根固定约 6 mV 的残留**（不随幅度变、输出一关就没）。而前端补偿在 550 kHz 处要补 ×7.12，会把这根残留放大成几十毫伏的 Upp 虚高。

`lsa_touch.StepCalib._measure_env()` 在信号源是 DG4202 时，给测量子进程注入三个环境变量（AFG 不加，行为不变）：

| 变量 | 值 | 作用 |
|---|---|---|
| `LSA_EQ_FHI_HZ` | 520000 | 补偿只做到 520 kHz |
| `LSA_EQ_LP_HZ` | 520000 | 补偿后再加一道硬低通 |
| `LSA_FIT_RESID_MAX` | 0.15 | 放宽拟合残差门限，避免退回分位数法 |

前两个解决"残留被放大"，第三个解决"小信号拟合残差刚过门限 → 退回分位数法 → Upp 系统性偏高约 10 mV"。

## 8. 已解决的关键问题（按代价排序）

| # | 现象 | 根因 | 处置 |
|---|---|---|---|
| 1 | 谐波"写得进但没输出" | `HARMonic:USER` 掩码默认全关 | 写掩码作为最后一步 |
| 2 | DG 的 ARB 输出峰峰值减半、h2 42% | `DATA:DAC` 是偏移二进制，发了有符号码 → 全波整流 | `+8192` 并夹到 `0..16383` |
| 3 | 小信号 Upp 恒定偏高约 10 mV | 拟合残差刚过 0.03 门限 → 退回分位数法 | `LSA_FIT_RESID_MAX=0.15` |
| 4 | 50 mV 档 `f1` 被认成 600 kHz | 550 kHz 处补偿 ×7.12 把固定残留放大 | 补偿带限到 520 kHz |
| 5 | 树莓派上 `select()` 等不到数据 | 内核 usbtmc 不替你做 bulk IN | 直接阻塞 `read()` |
| 6 | 查询之后所有应答错位一格 | 查了写-only 节点，或空帧被吞 | `resync()` + 空帧计数 + 失步保护 |
| 7 | 写完命令偶尔不生效 | 仪器偶发吞命令（谐波表尤其明显） | 读回核对 + 自动补写 |
| 8 | 换了树莓派后 `PermissionError` | `~/lsa` 由 root 创建 | `chown -R` 到登录用户 |
