### 步骤 3：滤波器指标核算（S2）

**动作**：用解析式 + scipy 复核二阶 Butterworth 在 fc=450 kHz 的响应。

**结果**：

| f | 衰减 |
|---|---|
| 321 kHz | −1.00 dB（−1 dB 通带边界） |
| 450 kHz | −3.01 dB |
| 1.8 MHz | **−24.12 dB** ✅ 满足题给 −24 dB |

**结论**：用户给的滤波器参数自洽；但"1 dB 通带纹波"与 Butterworth（最大平坦）矛盾。

### 步骤 4：拿到赛题后的重新核算 —— 发现致命问题

**动作**：用户提供赛题原文（四项要求 + 7 条说明）。

**致命发现**：题 2/3 的信号上限是 **500 kHz**，而滤波器 fc = 450 kHz：

| 分量 | 衰减 | 对 125 mV 的误差 | 判定（±5 mV） |
|---|---|---|---|
| 400 kHz | −2.11 dB | −21.5% | ❌ |
| **500 kHz** | **−4.02 dB** | **−37.1%** | ❌ |

**→ 现有滤波器不能用于测量通道，拐点必须提高。**

### 步骤 5：抗混叠与采样率分析

**动作**：分析题 3 的单频干扰 u₃（200 mVpp，f₃ ≥ 1 MHz）在采样后的折回行为。

**关键认识**：

```
折回频率 fold(f₃, fs) = |f₃ − k·fs|，取 ≤ fs/2
```

| 折回落点 | 数字滤波能否处理 |
|---|---|
| **> 500 kHz（带外）** | ✅ 数字低通干净滤除，**与模拟阶数无关** |
| **≤ 500 kHz（带内）** | ❌ **物理上不可分离** |

**二阶模拟滤波在 1 MHz 处最多给 −14 dB（fc=450k），达不到所需的 −32 dB。**
碰撞窗口占 [1,12] MHz 的 23%~50%。

### 步骤 6：换采样率重试策略的提出与验证

**动作**：既然碰撞窗口由 fs 决定而 f₃ 固定 → **换 fs 重试**。

**仿真验证**（二阶 fc=900k 模拟 + 12bit 量化 + 数字 8 阶 560k + Flat-top 窗）：

| 场景 | 结果 |
|---|---|
| 无干扰（200/400/500 kHz） | 谱线误差 +0.83 / −0.33 / −0.87 mV ✅ |
| **f₃ 扫 16 点，允许 4 档重试** | **16/16 通过（100%）** ✅ |
| **对照：固定 fs=2.0M 不重试** | **6/16 失败（38%）** ❌ |

**→ 换 fs 重试是必需机制，不是可选优化。**

### 步骤 7：时间预算核算

**动作**：按实测 10 Mbps 有效吞吐，逐模式核算耗时。

**结果**：

| 模式 | 采集 | 传输 | 分析 | 合计 |
|---|---|---|---|---|
| 频谱 1ch N=16384 | 8.2 ms | 26.2 ms | 15 ms | **49 ms** |
| 时域 3ch N=8192 | 4.1 ms | 39.3 ms | 20 ms | **63 ms** |

4 档重试 = **192 ms**；最坏组合 = **300 ms**。
**对 2 秒要求有 6.7 倍余量 → 时间不是瓶颈。**

### 步骤 8：方案定稿

三条关键设计决策：

1. **二阶滤波器拐点 450 kHz → 900 kHz**（唯一真正的模拟改动）
2. **换采样率重试（4 档）**（纯软件，解决干扰折回）
3. **频谱模式只采 1 通道**（纯软件，解决 10 Mbps 带宽约束）

## 2. 系统技术方案

### 2.1 总体架构

```
┌─────────────────────────── 模拟前端（改板）───────────────────────────┐
│  BNC 输入(50Ω)                                                        │
│    → [继电器 K1/K2: 源选择 + AC/DC 耦合]                              │
│    → INA128 仪表放大器 (BL1551B 选 R_G: ×2.00 / ×20.16)               │
│    → THS4521 全差分放大器 (×1.96)                                     │
│    → ★ 二阶 Butterworth LPF, fc = 900 kHz ★  ← 唯一模拟改动           │
│    → 33Ω + 100pF → ADC 差分输入                                       │
└───────────────────────────────────────────────────────────────────────┘
                                  ↓
┌─────────────────────────── STM32G474RET6 ─────────────────────────────┐
│  TIM8 TRGO2 触发  ← 采样率档位表 (2.0/2.5/3.0/4.0 MSPS)               │
│  ADC1/ADC2/ADC5  真差分 (DIFSEL + ADC_DIFFERENTIAL_ENDED)             │
│  DMA1 Ch1/2/3    突发块搬运 (N=8192 或 16384 点)                      │
│  12-bit 打包 → UDP → W5500 (10 Mbps)                                  │
│  TCP 5000 接收控制命令                                                 │
└───────────────────────────────────────────────────────────────────────┘
                                  ↓ 100M 以太网直连
┌─────────────────────────── 树莓派 (≥6" 显示) ─────────────────────────┐
│  UDP 收包 → 按 sample_idx 拼帧 → 数字低通(8阶 560k)                   │
│  → 通带校正 → FFT → 谱线识别 → 换 fs 重试判定 → 测量 → 显示           │
└───────────────────────────────────────────────────────────────────────┘
```

### 2.2 工作模式

| 模式 | 用途 | 通道数 | N | 采样率 | 单次耗时 |
|---|---|---|---|---|---|
| **波形模式** | 题 (1)：显示 1 或 3 个完整周期 | 3 | 8192 | 按输入频率自动/键控 | 63 ms |
| **频谱模式** | 题 (2)(3)(4) | **1** | 16384 | 多档重试 | 49 ms/档 |
| **AGC 核查** | 前置增益档确认 | 1 | 2048 | 2.0 MSPS | 44 ms |

### 2.3 采样率档位表

| 档 | fs | TIM8 ARR（170 MHz, PSC=0） | 实际 fs | 误差 |
|---|---|---|---|---|
| 0 | 2.0 MSPS | 84 | 2.0000 MSPS | 0 |
| 1 | 2.5 MSPS | 67 | 2.5000 MSPS | 0 |
| 2 | 3.0 MSPS | 56 | 2.9825 MSPS | −0.6% |
| 3 | 4.0 MSPS | 42 | 3.9535 MSPS | −1.2% |

> `ARR = round(170e6 / fs) − 1`。实际 fs 以 `170e6/(ARR+1)` 为准并上报给上位机，**不用标称值**。

**为什么选这四个档**：仿真显示该组合对 f₃ ∈ [1, 12] MHz 的"至少一档把干扰折到带外"覆盖率为 **100%**。

### 2.4 ADC 与时钟约束

| 项 | 值 | 说明 |
|---|---|---|
| ADC 时钟 | 42.5 MHz（SYSCLK/4） | 现状，≤2.83 MSPS 够用 |
| ADC 时钟上限 | 60 MHz | DS12288；改成 SYNC/2 = 85 MHz **超限** |
| 采样时间 | 6.5 周期 | ≈153 ns，兼顾建立与速度 |
| 单次转换 | 12.5 + 6.5 = 19 周期 | 42.5 MHz 下 447 ns |
| 单通道上限 | **2.24 MSPS** | 42.5 MHz + 6.5 周期采样 |
| 单通道上限 | 2.83 MSPS | 42.5 MHz + 2.5 周期采样 |
| 单通道上限 | 4.00 MSPS | 60 MHz 异步 + 2.5 周期采样 |

⚠️ **档位 2/3（3.0 / 4.0 MSPS）需要 2.5 周期采样时间**，即把 `SamplingTime` 从 6.5 改为 2.5。
考虑到板上已有 100 pF 差分电容（采样电荷缓冲），2.5 周期（59 ns）可接受但裕度小。
**若实测精度不足，档位 2/3 可降为 6.5 周期（对应 2.24 MSPS，重算 ARR）。**

### 2.5 分辨率与精度预算

×2.00 档，总增益 = 2.00 × 1.96 = 3.92，VREF = 3.0 V，12-bit 差分（±2047）：

| 输入 Upp | 差分峰峰码 | 等效位数 | LSB（折算输入） |
|---|---|---|---|
| 50 mVpp | 133.7 | 7.1 bit | 373.9 µV |
| 100 mVpp | 267.5 | 8.1 bit | 373.9 µV |
| 250 mVpp | 668.7 | 9.4 bit | 373.9 µV |

**量化误差分析**：

| 项 | 值 | 占 ±5 mV 预算 |
|---|---|---|
| 量化噪声 RMS（全带） | 107.9 µV | 2.2% |
| **FFT 单 bin 噪声（N=16384）** | **1.19 µV** | **0.02%** ← 谱线测量余量 72 dB |
| 数字滤波后带内噪声 | 88.1 µV | 1.8% |

**结论**：7.1 bit 看似低，但靠 FFT 相干积累，**±5 mV 指标有充裕余量**。

## 3. 关键参数推导

### 3.1 电压换算公式

```
V_in[uV] = (raw - offset_code) × VREF_uV / 2047 / (G_ina × A_fda)
```
其中 `VREF_uV = 3_000_000`，`G_ina ∈ {2.002, 20.157}`，`A_fda = 1.96`（需实测标定）。

### 3.2 增益链核算

```
INA128:  G = 1 + 50 kΩ / R_G
         R_G = 49.9 kΩ (R110, RP0402BRD0749K9L) → G = 2.002
         R_G = 2.61 kΩ (R109, 0402WGF2611TCE)   → G = 20.157

THS4521: A_fda = Rf / Rg = 2.49 kΩ / 1.27 kΩ = 1.9606
         Rf = R113/R120 (0402WGF2491TCE)
         Rg = R114/R117 (RT0402BRD071K27L)

总增益 = G_ina × A_fda
       = 2.002 × 1.9606  = 3.925   （×2 档）
       = 20.157 × 1.9606 = 39.52   （×20 档）
```

| 档 | 单端满量程（幅值） | 满量程 pp |
|---|---|---|
| ×2.00 | ±765 mV | 1531 mVpp |
| ×20.16 | ±76 mV | 152 mVpp |

**题 2/3 输入 50~250 mVpp → 只能用 ×2.00 档**（×20 档在 250 mVpp 时削顶）。

### 3.3 二阶抗混叠滤波器（推荐参数）

**fc = 900 kHz，二阶 Butterworth**：

| f | 衰减 |
|---|---|
| 10 kHz ~ 200 kHz | ≈ 0 dB |
| 400 kHz | −0.17 dB |
| **500 kHz** | **−0.40 dB** ✅ |
| 1.0 MHz | −4.02 dB |
| 2.0 MHz | −14.05 dB |

**设计要点**：
- 通带（≤500 kHz）平坦度优于 0.5 dB → 满足分量幅值误差
- 高频抑制弱 → **靠换 fs 把干扰折到带外，由数字低通处理**
- 剩余高频衰减靠 ADC 前的 100 pF + 33 Ω（拐点约 48 MHz）与后续数字滤波

> ⚠️ 若做过冲/群延迟敏感，可考虑 fc = 800 kHz（500 kHz 处 −0.62 dB），抑制略好。

### 3.4 数字低通（上位机）

**8 阶 Butterworth，fc = 560 kHz**：
- 500 kHz 处约 −0.03 dB（基本不压分量）
- 800 kHz 处约 −45 dB（抑制折回的干扰）
- 必须与模拟滤波器响应合并做**通带校正**，否则分量幅值有系统偏差

### 3.5 窗函数选择

| 用途 | 窗 | 相干增益 |
|---|---|---|
| 幅值测量 | Flat-top | 0.2156 |
| 谐波/THD | Blackman-Harris | 0.35875 |
| 通用 | Hann | 0.5 |

**必须做相干增益补偿**（除以 `sum(w)/N`），否则幅度系统性偏低。

```
偏移  长度  字段          类型      说明
0     4     magic         uint32    0x4C534D54 ('LSMT')
```

## 5. 换采样率重试算法

### 5.1 流程

```
输入: 当前档位 fs_idx
输出: 干净的测量结果（或标注置信度）

1. 用档位 fs_idx 采集 N 点（1 通道），数字低通 → FFT
2. 找谱峰：取幅度最大的若干峰（最多 6 个）
3. 识别信号结构：
   - 设最强峰为基波 f1
   - 检查其余峰是否落在 k·f1 附近（±2%）
   - 若 2~3 个峰构成谐波关系 → 信号识别成功
4. 判断每个强峰的"来源"：
   - 对每个 k = 1..K，候选源频率 f_src = k·fs ± f_peak
   - 若某峰的幅度显著高于同位置谐波的合理预期，且不在 k·f1 上
     → 判定为折回的干扰
5. 决策：
   - 无异常强峰 → 输出结果（干净）
   - 有异常强峰 → fs_idx++，回到 1（最多 4 档）
6. 4 档都失败 → 输出误差最小的一档，并标注"置信度低"
```

### 5.2 判别要点

| 判据 | 阈值 | 说明 |
|---|---|---|
| 谐波关系容差 | ±2% | 允许 FFT 分辨率误差 |
| "异常强峰" | 幅度 > 最小谐波 × 5 | 干扰 200 mVpp 远大于谐波 |
| 陷波保护宽度 | ±10 kHz | 避免削掉相邻谐波 |

### 5.3 备选兜底

若 4 档都不干净，仍可对最强异常峰做**数字陷波**（IIR notch，Q≈40），
代价是该频点附近的谐波会受损。仅在前述策略失败时使用。

### 5.4 时间开余量

单档 49 ms，4 档 192 ms。若实测能容忍更多档位，可加到 6 档（288 ms）进一步提升覆盖率。

#### ADC 差分配置

```c
/* 差分模式：单通道、不扫描 */
hadc1.Init.ScanConvMode    = ADC_SCAN_DISABLE;
hadc1.Init.NbrOfConversion = 1;
hadc1.Init.ExternalTrigConv = ADC_EXTERNALTRIG_T8_TRGO2;   /* 保持 */

ADC_ChannelConfTypeDef c = {0};
c.Channel      = ADC_CHANNEL_1;               /* ADC1: IN1 = 差分正端 */
c.Rank         = ADC_REGULAR_RANK_1;
c.SingleDiff   = ADC_DIFFERENTIAL_ENDED;      /* ← 关键 */
c.SamplingTime = ADC_SAMPLETIME_6CYCLES_5;
c.OffsetNumber = ADC_OFFSET_NONE;
HAL_ADC_ConfigChannel(&hadc1, &c);            /* 内部会写 DIFSEL 与配对通道采样时间 */
```

> HAL 在 `SingleDiff == ADC_DIFFERENTIAL_ENDED` 时会自动设置配对通道（n+1）的采样时间，
> 见 `stm32g4xx_hal_adc.c` 的 "Configuration of differential mode" 分支。

#### 三路 ADC 同步

```c
#define ADC_CH_COUNT  3
static volatile uint8_t ht_mask = 0, tc_mask = 0;

void HAL_ADC_ConvHalfCpltCallback(ADC_HandleTypeDef* hadc)
{
    uint8_t bit = (hadc->Instance==ADC1) ? 0x01 : (hadc->Instance==ADC2) ? 0x02 : 0x04;
    ht_mask |= bit;
    if (ht_mask == 0x07) { ht_mask = 0; g_buf_ready |= 0x01; }
}
/* Cplt 同理，置 g_buf_ready |= 0x02 */
```

⚠️ 需加**超时保护**：若超过 10 ms 未凑齐 3 路，复位掩码并计数上报。

#### 电压换算

```c
/* raw 为 12-bit 差分码，范围 -2047..+2047 */
int32_t raw = (int32_t)(int16_t)adc_buf[idx];
int32_t mv  = (int32_t)((int64_t)(raw - g_offset_code) * 3000
                        / 2047 / (int32_t)(g_total_gain * 100));  /* 定点化 */
```

或保留浮点（G474 有 FPU）：
```c
float v_in = (raw - g_offset_code) * 3.0f / 2047.0f / g_total_gain;
```

#### 采样率设置

```c
static const uint32_t arr_tbl[FS_COUNT] = { 84, 67, 56, 42 };  /* 2.0/2.5/3.0/4.0 MSPS */

void SampleClock_Set(uint8_t idx)
{
    __HAL_TIM_MOE_DISABLE(&htim8);
    __HAL_TIM_SET_AUTORELOAD(&htim8, arr_tbl[idx]);
    htim8.Instance->EGR = TIM_EGR_UG;
    __HAL_TIM_MOE_ENABLE(&htim8);
    g_fs_hz = 170000000UL / (arr_tbl[idx] + 1);
}
```
