## 0. 方案一句话

**新增一块「4 阶伪差分滤波 + 一分三」前端板**，放在现有板之前；**现有板只改二阶 FDA 的 fc**（450 kHz → 520 kHz 设计点）；固件按已完成的第一批改造继续推进。

| 板 | 角色 | 改动 |
|---|---|---|
| **新前端板** | 4 阶 Chebyshev 抗混叠滤波 + 一分三 | 全新 |
| **现有板** | INA128 增益 + FDA 差分驱动 + ADC + 网络 | **只改二阶 FDA 元件值** |
| **树莓派** | 运算 + 显示 + 幅频标定 | 全新（任务书已就绪） |

## 1. 系统架构

### 1.1 全链路（全系统伪差分）

**架构约束**：全系统采用**伪差分**方式，SMA/BNC 输入端以 **AGND 作为 IN−**，
信号是单端对 AGND，最终由 FDA 转成真差分送入 ADC 差分对。

```
┌────────────────── 新增前端板 ──────────────────┐
│                                                │
│  BNC(50Ω) IN+ ──┐                              │
│                 ├─► [4 阶 Sallen-Key 滤波] ──┬─► OUT_A │
│  AGND      IN- ──┘   292.53k / 505.32k 两级   ├─► OUT_B │ 一分三
│                                               └─► OUT_C │
└────────────────────────────────────────────────────────┘
        │  三路相同信号（高阻抽头，无衰减）
        ▼
┌────────────────── 现有板（每通道）──────────────┐
│                                                │
│  IN ─► [继电器 K1/K2: 源选择 + AC/DC 耦合]      │
│       ─► [INA128 仪表放大器 ×2.00 / ×20.16]     │
│       ─► [THS4521 FDA ×1.96]  ★改 fc: 450k→520k★│
│       ─► 33Ω + 100pF ─► ADC 差分对              │
└────────────────────────────────────────────────┘
        │  UDP (10 Mbps)
        ▼
┌──────────── 树莓派 + ≥6" 显示 ─────────────────┐
│  收包 → 数字低通 → 幅频标定 → FFT → 谱线识别     │
│       → 测量 → 显示                            │
└────────────────────────────────────────────────┘
```

### 1.2 为什么这样分工

| 决策 | 理由 |
|---|---|
| 滤波放**前端板**、位置在**现有板之前** | 一套滤波器供三通道共用，省 3 倍器件 |
| 前端板做**一分三**而非三套滤波 | 三路 INA128 输入阻抗 ~10 MΩ 并联仍 ~3.3 MΩ，对 50 Ω 源可忽略，**无需缓冲** |
| 现有板只改 **二阶 FDA 的元件值** | 唯一需要动、也最容易动的参数 |
| 抑制干扰交给**前端 4 阶 + 二阶 FDA** | 两节共同承担，单档即达标，不需换采样率重试 |

## 2. 指标需求推导

### 2.1 赛题硬性指标

| 项 | 题 1 | 题 2 | 题 3 |
|---|---|---|---|
| 输入 | 100~250 mVpp，10k~200 kHz | 50~250 mVpp，10k~500 kHz | u₂ + u₃；u₃ 单频 200 mVpp，**f₃ ≥ 1 MHz** |
| (2) 时域 | Upp/Urms 误差 ≤5 mV；f₁ 误差 ≤1 kHz | 同 | 同 |
| (3)(4) 频域 | 频谱 + 各分量幅值误差 ≤5 mV | 同 | 同（需抑制 u₃） |
| 每项耗时 | ≤2 s | ≤2 s | ≤2 s |

**说明条款（硬性）**：单路 5V 供电 · 显示屏 ≥6" · **板上焊 BNC 座**。

### 2.2 抗混叠滤波需求

**最坏情况 f₃ = 1 MHz**（因为是下界），200 mVpp 要压到 ≤5 mVpp：

```
所需衰减 = 20·log10(5/200) = −32 dB   ← 对 1 MHz 的要求
```

同时 500 kHz 分量衰减必须 **≤1 dB**（否则 ±5 mV 指标超差）。

### 2.3 分工方案

| 级 | 类型 | 对 1 MHz 的贡献 |
|---|---|---|
| 前端 4 阶 | Chebyshev 0.5 dB | −31.11 dB |
| 二阶 FDA | Chebyshev 0.5 dB | −7.28 dB |
| **合计** | | **−38.39 dB** ✅（余量 6.39 dB） |

**为什么用 4 阶而不是 6 阶**：6 阶的最高 Q 达 6.513，Stage 2 的 GBW 需求飙到 **329 MHz**，
必须用昂贵的超高速运放。4 阶把最高 Q 降到 2.941，GBW 需求 **148.62 MHz**，
用 **THS4551（150 MHz）** 即可。

## 3. 前端滤波器设计方案（第一部分）

### 3.1 设计规格

```
Name: Lowpass, Multiple Feedback Fully Differential, Chebyshev
Part: Ideal Opamp  →  实选 THS4521 / THS4551
Order: 4
Number Of Stages: 2
Gain: 1 V/V (0 dB)
Allowable PassBand Ripple: 0.5 dB
Passband Frequency: 490 kHz
Corner Frequency Attenuation: -3 dB
Stopband Attenuation: -32 dB
Stopband Frequency: 1 MHz
Circuit Topology: MultipleFeedback_Fully_Differential
```

> **实现形式**：全系统伪差分，因此按 **单端 Sallen-Key** 实现：
> 运放同相端（IN−）接 **AGND**，信号走 IN+。每节用 1 片双运放的一半，2 节共 **2 片运放**。
> （FilterPro 的 `MultipleFeedback_Fully_Differential` 拓扑在伪差分下等效为单端 MFB，
> 元件值可直接使用。）

### 3.2 逐节参数（FilterPro 导出报告原文）

| 节 | 截止频率 | 品质因数 | Passband Gain | **Min GBW req.** | 选用运放 |
|---|---|---|---|---|---|
| Stage 1 | **292.5312 kHz** | **0.705** | 1 | **20.6234 MHz** | **THS4521**（145 MHz）✅ |
| **Stage 2** | **505.3225 kHz** | **2.941** | 1 | **148.6153 MHz** | **THS4551**（150 MHz）✅ |

> 验证：`GBW需求 = 0.1000 × Q × fc`
> - Stage 1：0.1 × 0.705 × 292.5312 = 20.6234 MHz ✅
> - Stage 2：0.1 × 2.941 × 505.3225 = 148.6153 MHz ✅

### 3.5 板级设计要点

#### 3.5.1 信号链

```
BNC(50Ω) IN+ ──┬─► [Stage1 Sallen-Key] ─► [Stage2 Sallen-Key] ──┬─► OUT_A
               │                                                  ├─► OUT_B
AGND      IN- ──┘                                                  └─► OUT_C
```

**一分三的做法**：不是电阻分压，而是**三个高阻抽头**。
三路 INA128 输入阻抗并联后仍 ~3.3 MΩ，对滤波器输出负载影响可忽略。
抽头建议每路串 **0 Ω 或 22 Ω** 用于隔离与调试。

#### 3.5.2 每节拓扑（单端 Sallen-Key / 伪差分）

| 项 | 接法 |
|---|---|
| 运放同相端（IN−） | 接 **AGND** |
| 信号 | 走 **IN+** 单端 |
| 反馈电容 C1 | 跨接输出与中间节点 |
| 接地电容 C2 | 中间节点到 AGND |
| 直流耦合 | **不做电平搬移**，保持与现有板 INA128 的 DC 通路一致 |

#### 3.5.3 电源与 AGND（**关键**）

现有板：
- 数字/模拟电源分离（`+3V3(DGND)` / `+3V3(AGND)`，经磁珠隔离）
- **AGND 与 DGND 是两个独立网络**，由 R73+R74（两个 0 Ω 并联）单点桥接
- `LM2776` 提供 **−5V(AGND)**；`MAX6071` = 3.0 V 基准
- 继电器用 +12 V

**前端板的伪差分"AGND"必须与现有板 AGND 同电位**，否则 INA128 输入失调会被放大 39 倍。

| 项 | 建议 |
|---|---|
| 供电 | 从现有板取 **+5V(AGND)** 和 **−5V(AGND)** |
| 参考 | 前端板 AGND 直连现有板 AGND（**单点**，与大电流回路分开走） |
| 实测验收 | 两板 AGND 电位差 **< 1 mV** |
| 若用单电源 | 需生成 **+2.5 V 中点**作为伪差分参考，并与现有板 AGND 电平对齐 |

#### 3.5.4 元件精度

| 元件 | 要求 | 说明 |
|---|---|---|
| 电阻 | **E96 1%** | 已验证取值 |
| **C1 与 C1diff** | **1% C0G，成对匹配** | 差分两半不一致会劣化共模抑制 |
| C2 | E24 5% 可接受 | 不在差分对称位置 |
| 运放 | Stage1 = THS4521 / Stage2 = **THS4551** | 按 GBW 需求选 |

#### 3.5.5 群延迟

4 阶 Chebyshev @490 kHz 的带内群延迟约 **1.5~2.6 µs**，平滑无尖峰。
对"1 个完整周期"显示有轻微线性相移，可接受。

### 5.1 增益与分辨率

现有硬件两档增益（INA128 × FDA）：

| 档 | INA128 | FDA | 总增益 | 单端满量程 |
|---|---|---|---|---|
| **×2** | 2.002（R_G=49.9 kΩ） | 1.9606 | **3.925** | ±765 mV（1531 mVpp） |
| ×20 | 20.157（R_G=2.61 kΩ） | 1.9606 | **39.52** | ±76 mV（152 mVpp） |

| 输入 Upp | 差分输出 | 满量程占用 | 等效位数 |

| 50 mVpp | 196 mVpp | 3.3% | 7.1 bit |
| 250 mVpp | 981 mVpp | 16.3% | 9.4 bit |

## 6. 运放选型汇总

| 位置 | 节 | Min GBW req. | 选用 | 余量 |
|---|---|---|---|---|
| 前端板 | Stage 1 | 20.6234 MHz | **THS4521**（145 MHz） | 充裕 |
| **前端板** | **Stage 2** | **148.6153 MHz** | **THS4551**（150 MHz） | **+0.93%** ⚠️ |
| 现有板 | 2 阶 FDA | 约 55 MHz | **THS4521**（145 MHz） | 充裕 |

**唯一风险点**：Stage 2 余量 0.93%。
FilterPro 的 Min GBW 是**保守估算**（保证极点位置准确），实际偏差应在零点几 dB 量级。

**建议**：用 **THS4551 的 SPICE 模型在 TINA-TI 里复跑**，确认 500 kHz 与 1 MHz 两点仍达标。

**退路**：4 阶降到 **480 kHz** → Stage2 GBW 145.58 MHz（余量 3%），通带峰值 +0.745 dB（仍安全）。
备选数据见 `04_备选_4阶前端其它设计点\`。

## 11. 风险与待确认项

### 11.1 高风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| **Stage 2 的 THS4551 余量仅 0.93%** | Stage 2 的 Q 可能略降 | TINA-TI 实模型复跑；退路降 fc 到 480 kHz |
| **前端板 AGND 与现有板不一致** | INA128 失调被放大 39 倍 | 单点连接，实测电位差 <1 mV |
